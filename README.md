# Vít Charvát's Portfolio

## URL: https://vitekcharvat.github.io

A personal portfolio based on design B2 "Mountain Lake". The brief is in `PRD.md`, a more detailed description is in `PORTFOLIO.md`. The website text is in English.

## Files

- `index.html`: home page (intro with the painting, Projects, About me, Contact).
- `skolni-projekty.html`: the More projects subpage.
- `404.html`: page for addresses that don't exist (GitHub Pages uses it automatically).
- `style.css`: all custom styling, with comments in Czech.
- `sitemap.xml`, `robots.txt`: for search engines.
- `assets/images/`: the B2 painting in WebP and the share preview `og-image.jpg`.
- `assets/src/hero-jezero.svg`: source of the painting.
- `assets/favicon.svg`: browser tab icon.
- `assets/OBRAZKY.md`: where the images came from and how to rebuild them.
- `docs/navrh-b2.html`: reference mockup from the canvas (not part of the website).
- `googlea39b896c1462c2f5.html`: site verification for Google Search Console, do not delete.

## Libraries

- [Bootstrap 5.3.8](https://getbootstrap.com/docs/5.3/getting-started/introduction/), CSS only: container, spacing, utility classes.
- Google Fonts: [Newsreader](https://fonts.google.com/specimen/Newsreader) for headings, [Figtree](https://fonts.google.com/specimen/Figtree) for body text.
- [Font Awesome Free 6.7.2](https://fontawesome.com/): GitHub, envelope and external link icons.

The website has no `<script>` at all.

## Validation

The Validate HTML and Validate CSS buttons in the footer run W3C validation of the published page in a new tab.

Check on 27 Oct 2026: all three HTML files pass W3C Nu with no errors or warnings, and `style.css` passes the W3C CSS Validator (CSS3 + SVG) with no errors. The page doesn't overflow sideways at widths of 320, 390, 768 and 1440 px.
