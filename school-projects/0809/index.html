Programming Languages

Python

Python is a high-level, interpreted programming language known for its simplicity and readability. It supports multiple programming paradigms, including procedural, object-oriented, and functional programming. Python is widely used in web development, data analysis, artificial intelligence, scientific computing, and more.

  • Simple and readable syntax, a good first language
  • Automating repetitive tasks, such as renaming files
  • Data processing and analysis (pandas, NumPy)
  • Artificial intelligence and machine learning
  • Server-side web development with Django and Flask

JavaScript

JavaScript is a versatile, high-level programming language primarily used for web development . It allows developers to create interactive and dynamic web pages, and it can be run on both the client-side (in the browser) and server-side (using environments like Node.js). JavaScript supports object-oriented, imperative, and functional programming styles, making it a popular choice for building modern web applications.

  • The only language browsers understand directly
  • Responds to user actions, such as clicking a button
  • Changes page content without reloading the page
  • Loads data from a server in the background
  • Also runs outside the browser thanks to Node.js

HTML

HTML (Hypertext Markup Language) is the standard markup language used to create and structure content on the web. It provides the basic building blocks for web pages, allowing developers to define elements such as headings, paragraphs, links, images, and multimedia. HTML is often used in conjunction with CSS (Cascading Style Sheets) and JavaScript to create visually appealing and interactive websites.

  • A markup language, not a programming language
  • Defines the structure of a page: headings, paragraphs, lists
  • Adds images, links and tables
  • The current version is HTML5
  • Code correctness is checked at validator.w3.org

CSS

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation and layout of HTML documents. It allows developers to control the visual appearance of web pages, including colors, fonts, spacing, and positioning of elements. CSS enables the separation of content from design, making it easier to maintain and update the look and feel of websites. It also supports responsive design, allowing web pages to adapt to different screen sizes and devices.

  • Styles the page: colors, fonts, spacing
  • Controls the layout of multiple pages at once
  • Supports responsive design for different screen sizes
  • Can be written in separate files or inline
  • The current version is CSS3
